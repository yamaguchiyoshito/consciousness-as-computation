# 読み方と表示環境

[連載目次へ](../README.md)

## GitHubのMarkdownで読む

リポジトリのREADMEから各回を開き、Preview表示を使う。RawやCode表示は原稿テキストを見るためのものであり、図は表示されない。各回の冒頭と末尾に、前回・目次・次回のリンクがある。

## HTMLで読む

GitHub Pagesが有効なら、公開URLのトップページが目次になる。手元で再生成した場合は `_site/index.html` をブラウザで開く。サーバー起動は不要である。全9回を一つのファイルで読む場合は `_site/complete.html` を開く。どちらも外部通信をしない。

## 再生成する

Python 3.11以降とPandoc 3.xを使う。Python標準ライブラリだけを使うため、pipによる追加導入は不要である。Pandocの導入方法は[公式インストール案内](https://pandoc.org/installing.html)を参照する。

```sh
python --version
pandoc --version
python scripts/validate.py
python scripts/build.py
```

WindowsでPythonコマンドが `py` の場合は `py -3 scripts/build.py` とする。HTMLを作る前にMarkdownの検査を行い、警告を残したまま公開しない。

## 表示の設計

本文は1行がおよそ45字になる幅（720px）、16px、行間1.8で組んである。節見出しは太字のみで、縦線や下線は引用や表との区別のために使わない。各回の冒頭と末尾にある枠つきの行が前後の回へのリンクで、末尾には次回の題名を添えている。図は本文幅に収め、細い枠で本文と区別する。電話幅では図が縮小されるので、図中の文字を読むときは図を拡大するか、横向きにする。

## 図と数式の読み分け

挿絵は原典の転載ではなく、本連載の説明のために作成した概念図である。ぼやけた円は「境界を持たない結びつき」の視覚的な記号であり、矢印は必ずしも因果を表さない。破線の枠や円は、本連載が仮説として置いた概念を示す。キャプションに示す前提を併せて読む。

本文中の `U(x) = Σ_i w_i・f_i(x)` のような式は、考え方を表すための近似的な表記であり、脳にその式が実装されているという主張ではない。閲覧版では式だけの行を枠付きのブロックにして右端に式番号を置き、添字は下付き・上付き文字で描く。GitHubのPreviewでは `w_i` のままコード表記で表示される。各回の本文が、どこまでが提唱者の理論の参照で、どこからが本連載独自の仮説かを明示している。
